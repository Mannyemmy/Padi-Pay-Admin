## 🚀 Getting Started (3 Steps)

### Step 1: Install
```bash
cd d:\Dev\padi-pay-admin
npm install
```

### Step 2: Configure
```bash
# Copy the template
cp .env.local.example .env.local

# Add your Firebase credentials:
# NEXT_PUBLIC_FIREBASE_API_KEY=...
# NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
# etc.
```

### Step 3: Run
```bash
npm run dev
```
Visit: http://localhost:3000
